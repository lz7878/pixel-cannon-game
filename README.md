# 像素炮阵（Pixel Cannon）

一个参考“排队接人”消除玩法、改造成彩色大炮主题的手机竖屏原型。

## 玩法

- 底部炮队使用 4 列 × 2 排展示：第一排可选择，第二排半透明预览下一门炮。
- 点击第一排的大炮后，同列第二排会向前补位，后续大炮继续补到第二排。
- 大炮会自动攻击从下方暴露出来的同色方块。
- 没有可攻击目标的大炮会等待并占住炮位，装炮顺序是解谜关键。
- 默认开放 4 个炮位，可通过激励视频占位流程解锁第 5 个炮位。
- 4 个炮位堵塞时可通过视频解锁位救场；5 个炮位全部堵塞后挑战失败。

## 运行

直接打开 `index.html`，或在目录中启动任意静态服务器：

```bash
python3 -m http.server 5173
```

然后访问 `http://localhost:5173`。

当前版本是用于验证核心玩法的 Web 原型。视频按钮目前用 1.1 秒延时模拟完整播放回调；接入抖音小游戏时，在激励视频 `onClose({ isEnded: true })` 回调中调用 `unlockExtraSlot()`，并继续接入生命周期、存档与分享 API。
